SIMBG GRESIK — paket web

Struktur:
- index.html
- assets/logo.png
- assets/wallpaper.webp

Cara pakai:
1. Upload index.html dan folder assets ke repository GitHub Pages.
2. Pastikan wallpaper.webp berada di assets/wallpaper.webp.
3. Jika ingin musik, tambahkan assets/lagu.mp3.
4. Jika ingin mengganti link, edit atribut href pada index.html.

Kolase wallpaper dibuat dalam format 16:9 dan WebP agar lebih ringan untuk web.
